# Grandis Legacy VS AI v6.41 / Tutorial v0.67

Release date: 2026-09-14

## Mobile
- Shard Deck now displays the closed card back instead of Mana Shard artwork.
- Hero staging keeps its existing vertical Status/Skill and Attachment space, but the physical Hero card is centered horizontally in each lane.
- Native mobile page scrolling is unchanged.

## Tablet
- Portrait tablets use the existing mobile presentation and native scroll.
- Landscape tablets use the desktop battlefield and touch interaction.
- Landscape board/sidebar use the actual dynamic viewport height so the Phase Tracker actions no longer collide on short tablet screens.
- Hand cards expose PLAY/TRIBUTE legality before selection.
- Tapping a Hand card selects/raises it and opens the enlarged hover-style review; it does not open Card Preview automatically.
- Selected-card actions appear vertically beneath the enlarged review: Preview, Play, Tribute (only actions that are actually available are shown).
- Preview continues to open the dedicated Card Preview popup.
- Desktop mouse/hover behavior is unchanged.

## Tutorial
- Ultimate Tribute teaching now explicitly covers all three requirements: 200 EXP, named Bound Hero, and 1 matching Class Shard in the Shard Pool.

## Authority
- Source Stack remains v1.8.2; this release does not change gameplay rules.
- PvP reference remains v3.42.
