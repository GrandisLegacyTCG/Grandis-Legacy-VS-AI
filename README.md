# Grandis Legacy VS AI v6.41 + Tutorial v0.67

Release date: 2026-09-14.

This release keeps Source Authority Stack v1.8.2 gameplay unchanged and finishes the requested mobile/tablet interaction pass.

Current responsive behavior:
- **Phone/mobile:** keeps the established native-scroll mobile battlefield. Shard Deck now uses the card back, and each Hero is centered left-to-right inside its lane without changing the reserved Status/Skill area above or Attachment area below.
- **Tablet portrait:** uses the same scrollable mobile presentation as phone.
- **Tablet landscape:** uses the desktop-style non-scroll battlefield, fitted to the usable dynamic viewport. Touching a Hand card reproduces the enlarged desktop hover view; legal Play/Tribute states are visible before selection; selected-card actions are a vertical **Preview / Play / Tribute** stack when available. Preview remains the separate Card Preview popup.
- **Desktop:** preserves the existing mouse/hover interaction.

Tutorial v0.67 adds explicit Ultimate Tribute teaching: an Ultimate provides 200 EXP, is restricted to its Bound Hero, and requires 1 matching Class Shard in the Shard Pool.

Gameplay authority remains Source Stack v1.8.2.
