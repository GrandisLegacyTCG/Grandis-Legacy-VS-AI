# Grandis Legacy VS AI + Tutorial v5.57

GitHub Pages repository containing two separate applications:

- **VS AI** at the repository root: `https://grandislegacytcg.github.io/Grandis-Legacy-VS-AI/`
- **Tutorial** at `/tutorial/`: `https://grandislegacytcg.github.io/Grandis-Legacy-VS-AI/tutorial/`

The VS AI header links to Tutorial, Deck Builder, and PvP. Tutorial v0.31 remains a separate application bundle inside the same repository. Gameplay runtime/card data are unchanged by this navigation release.

## Deployment

Copy this package directly into the `Grandis-Legacy-VS-AI` repository root, commit, push, and wait for GitHub Pages to refresh.
