This release promotes Playtest Lab v0.14 on Source Authority Stack v1.8.2. VS AI v6.36 is the current local gameplay reference and Tutorial v0.62 shares the same gameplay runtime while adding explicit Shard-system teaching.

- **Shard Deck**, **Shard Pool**, **Mana Shard**, and **Class Shard** terminology;
- 12-card Shard Deck, 3 Starting Shards, Mana Regen starting at 1, and the current Shard return cycle;
- Ultimate-derived Class Shards and matching-Class-Shard Ultimate Tribute;
- blind opponent-Shard selection;
- Actual Draw / Arbalest draw-counter authority;

- Camouflage no-Exhaust, status stacking, Auto Center 1v1, and manual Reposition limit;

VS AI v6.36 also upgrades active AI decisions: Aurex can use its healing Class Ability when it has no same-turn Attack/Tactical use, Quick Reload/Rapid Chamber default to redraw, Mana/Arcane Surge spend only when useful, and active/defensive Racial Traits follow the current threat and finisher rules.
