# Grandis Legacy VS AI v5.44

## Casting gameplay fix
- A Hero with active Casting stays Exhausted through Draw Phase.
- Rank Up in the same tactical position no longer cancels Casting.
- Casting source identity follows the Hero progression rather than the exact Rank card ID.
- Reposition, Stun, defeat, or replacement still cancel Casting.
- Casting release recalculates its legal effect row, base damage, and modifiers from the current Hero at release.
- The target position remains locked.

## UI
- Desktop unavailable Response cards use the single-line label `Unavailable`.
- Hover/focus shows the runtime reason directly; no extra popup is opened.
- The remaining desktop lower stroke is removed.
- Mobile resource rows are slightly taller so Mana and card backs are not cropped.
- The dedicated Racial column keeps both tokens separated vertically.

PvP remains held and unchanged.
