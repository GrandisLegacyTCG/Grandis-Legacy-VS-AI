# Grandis Legacy VS AI v5.48 Release Note

## Mobile Legacy controls
- Legacy mode now uses the same mobile control anchors as Hero mode.
- The `!` control for viewing the defeated Hero under a Legacy is fixed at the top-left of the battlefield slot.
- The contextual `✦` Legacy Ability control remains fixed at the top-right.
- The two controls no longer cluster beside the Legacy name.

## Desktop
- Desktop keeps the approved Legacy name-row information control and existing action layout.

## Runtime / gameplay
- No gameplay rules, card data, legality, AI behavior, or runtime resolution changed.
- PvP remains unchanged at v2.5.16.
