# Grandis Legacy VS AI v5.46 Release Note

## Runtime / gameplay
- Corrected Double Casting to follow the FINAL printed text: both Elementalist and Elemental Lord may choose the same or a different legal Hero for activation 2/2.
- Each activation remains a separate attack resolution with its own Response Window.

## Desktop UI
- Unavailable Defense cards use the single-line label `Not Available`.
- Only one prioritized reason is shown through a custom hover/focus tooltip contained inside the Response Window.
- Native browser title tooltips are removed.

## Mobile UI / animation
- Hidden horizontal Hand scrollbar; swipe remains enabled.
- Stable space for up to two action buttons below every Hand card.
- Start Game focuses the Player Hand after the coin flip.
- Opening Hand, Rank Up draws, mandatory draws, and effect multi-draws animate/reveal one card at a time.

PvP is unchanged and requires a later parity port.
