# Grandis Legacy VS AI v5.41

## Scope
VS AI responsive presentation and bundled Public Deck Builder. PvP remains held and unchanged.

## Mobile battlefield
- Hero artwork is reduced slightly and Hero lanes are taller to create a dedicated top overlay gutter.
- Each Hero uses exactly one top-left `!` information control for statuses, Casting, Exhaust, and restrictions.
- Each Hero/Legacy uses exactly one top-right contextual action control for Racial Trait, Hero Ability, or Legacy Ability.
- Racial Tokens are shown compactly inside the Mana resource container instead of beside the Hand.
- HP overlays are anchored to the card top-right and cover the printed HP area while remaining upright during Exhaust.
- The bottom footer can be fully reached by normal scrolling.

## Deck Builder
- Bundled Public Deck Builder advances to v2.1.
- Legacy Setup > Default Hero Formation card previews are enlarged to 120 px wide and may extend the page vertically.

## Runtime/package synchronization
- Runtime Foundation remains v1.74 and Runtime Core remains v0.41; gameplay resolver behavior is unchanged.
- Application Runtime Sync advances to v2.26.
- UI Design Lock advances to v2.29.
