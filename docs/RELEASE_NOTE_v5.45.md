# Grandis Legacy VS AI v5.45

## Casting runtime
- Adds stable Hero instance identity to Casting commitment and release validation.
- Rank Up preserves the same instance and does not cancel Casting.
- Actual Reposition, Stun, defeat, or replacement still cancel Casting.
- Casting release recalculates effect row, base damage, and modifiers from the current Hero.

## UI
- Desktop unavailable Response cards use one-line `Unavailable`; hover/focus shows the runtime reason without another popup.
- Removes the remaining legacy gold baseline generated by `gl-app::after`.
- Mobile resources increase to 72 px so Mana/card backs are not cropped and Mana Regen remains visible.
- Mobile Racial Tokens stay vertically separated.
- Mobile Player Hand expands across the freed left/right space.

PvP remains held and unchanged.
