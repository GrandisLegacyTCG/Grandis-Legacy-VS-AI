# Shared Battlefield UI

This directory is the **one editable shared battlefield presentation source** for the combined VS AI + Tutorial repository.

- VS AI v6.42 = Shared Battlefield UI + Local/AI controller.
- Tutorial v0.68 = Shared Battlefield UI + Tutorial overlay/controller.
- UI Contract: v2.52.
- Desktop enlarged preview is a right-side, source-hover-only, `pointer-events:none` overlay.
- Counter image assets are reserved for Mana Regen. Deck/Status counts use numeric presentation.

Do not create a separately edited Tutorial battlefield fork. Deployment-specific files may consume this module, but shared presentation decisions belong here.
